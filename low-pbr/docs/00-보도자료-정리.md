# 00 보도자료 정리 — 「저PBR기업 최초 선정 및 공표」 (한국거래소, 2026.10.30 배포 · 11.2 조간)

원본: `source/2026-10-30_KRX_보도자료_저PBR기업_최초선정.pdf` (8쪽: 본문 3 + 붙임1 업종별 결과 + 붙임2 151사 명단)

## 1. 한 줄 요약
「자본시장 체질개선 방안」(2026.3.18) 후속으로, 시장·업종별 PBR이 3년(6반기) 내내 하위권인 기업 151사(유가 96·코스닥 55)를
처음 지정·공표. KIND 밸류업 페이지와 증권사 MTS·HTS에 "저PBR" 태그. PBR 개선계획을 공시한 기업은 빠질 수 있으나
6년(12반기) 장기 저PBR이면 공시해도 공표.

## 2. 숫자 흐름 (검산 완료)
```
PBR 산정 대상 2,431 (유가 779 · 코스닥 1,652)
  └ 저PBR 요건 해당 185 (115 · 70)
       └ 공표 제외 34 (19 · 15)  → 공표 151 (96 · 55)
PBR 개선계획 제출 62사 = 저PBR 해당 49(제외 34 + 제외불가 15) + 미해당 13
```
- 실효 선정률: 유가 115/779 = 14.8%(명목 25%), 코스닥 70/1,652 = 4.2%(명목 10%) — 지속성 요건이 걸러 냄.
- 붙임1 업종 행·열 합, 붙임2 업종별 사수, 모든 PBR ≤ 업종 기준값: 전부 일치 (`scripts/s00_press.py` assert).

## 3. 업종에서 보이는 것
- 유가 공표 96사 중 78%(75사)가 소재 23·산업재 22·자유소비재 18·필수소비재 12. 코스닥은 정보기술 17·산업재 10·헬스케어 10.
- 기준 PBR 업종 차이: 유가 정보기술 0.63 ↔ 유가 부동산 0.11.
- 경계값: 광동제약 0.51(유가 헬스케어 기준 0.51)·원익 0.51(코스닥 헬스케어 0.51)·E1 0.28(유가 에너지 0.28).
- 소규모 업종 특례: 코스닥 부동산(3사)·유틸리티(4사)는 최저 1사가 그대로 지정(동원개발·에코심플렉스).
- 유가 유틸리티(14사)·부동산(4사) 지정 0 — 지속성 요건 미충족으로 보임. 코스닥 업종미분류 16사는 선정 불가(실질 모집단 1,636).

## 4. 명단에서 보이는 것
- PBR 범위: 유가 SUN&L 0.06 ~ 광동제약 0.51, 코스닥 앱토크롬 0.07 ~ 원익 0.51.
- 지주회사 다수(이름에 홀딩스·지주 14사 + BGF·DL·코오롱 등). 그룹 계열 묶음: 롯데 3·무림 3·한솔·삼양·코오롱·KCC·태광·현대차·신세계.
- 대형사 포함(현대제철·롯데케미칼·이마트·롯데쇼핑·한화생명), 은행·금융지주는 없음.

## 5. 문서가 말하지 않는 것
1. 분모 "자본총계"의 연결/별도, 비지배지분 포함 여부 → 재현 가정 A2, 151사 PBR 대조로 판정.
2. 시점 불일치: 시가총액 9~10월 평균 ↔ 자본 6월 말(3분기 보고서 미사용).
3. 과거 반기 PBR 산정 방식 미기재 → 가정 A1(소급 동일 적용).
4. 하위 25%·10%의 반올림 규칙 → 가정 A4, 붙임1 기준 PBR로 판정.
5. 산정 대상 제외 "상장폐지 사유 발생 기업 등"의 범위 → docs/03 실측(시총·주가 미달 관리종목은 제외되지 않음).
6. PBR 개선계획 인정 요건 → KIND 공시 제목 "(PBR 개선 계획 제출 기업)"으로 62사 정확히 식별됨(docs/03).
7. 공표 후 계획 공시 시 해제 시점 → 지침상 다음 공표(2027.5)부터 연속 2회 제외로 해석.
8. 표현: "누적 3년"이지만 실제 요건은 7반기 중 6반기(최대 3.5년), 프로세스 그림의 "(9.21~10.22)"는 시가총액 구간.
