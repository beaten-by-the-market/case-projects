제29조 ( / 이사 및 감사의 수 / ) / ① / 이 회사의 이사는 3명 이상 8명 이하로 하고, 사외이사는 이사총수의 4분의 1이상으로 한다. / ② 이 회사의 감사는 1명 이상으로 한다. / ③ 이 회사는 사외의 이사 및 감사를 둘 수 있다.④ 사외이사의 사임·사망 등의 사유로 인하여 사외이사의 수가 / 제1항 / 에서 정한 이사회의 구성요건에 미달하게 되면 그 사유가 발생한 후 처음으로 소집되는 주주총회에서 그 요건에 합치되도록 사외이사를 선임하여야 한다. | 제29조 ( / 사내이사 및 사외이사의 수 / ) / ① / 이 회사의 사내이사는 3명 이상 6명 이하로 한다. / ② / 사외이사의 수는 사내이사의 수와 합산한 이사의 총수의 4분의 1 이상으로 한다 / . / ③ 사외이사의 사임·사망 등의 사유로 인하여 사외이사의 수가 / 제2항 / 에서 정한 이사회의 구성요건에 미달하게 되면 그 사유가 발생한 후 처음으로 소집되는 주주총회에서 그 요건에 합치되도록 사외이사를 선임하여야 한다. / 제29조 1 ( / 감사의 수 / ) / ① 이 회사의 감사는 1명 이상으로 한다. | 선임 대상별 / 내용의 / 명확화
제30조 ( / 이사 및 감사의 선임 / ) / ① / 이사와 감사는 주주총회에서 선임한다. 단, 이사와 / 감사의 / 후보자격은 추천위원회에서 추천된 자에 한하며이사의 선임 시 집중투표의 방법은 적용하지 않는다. / ② / 이사와 감사의 선임은 / 출석한 주주의 의결권의 과반수로하되 발행주식총수의 4분의 1이상의 수로 하여야 한다.그러나, 감사의 선임에는 의결권 없는 주식을 제외한 발행 / 주식총수의 100분의 3을 초과하는 수의 주식을 가진주주는 그 초과하는 주식에 관하여 의결권을 행사하지 못한다. | 제30조 ( / 사내이사 및 사외이사의 선임 / ) / ① / 사내이사는 주주총회에서 선임한다 / . 단, 후보자격은추천위원회에서 추천된 자에 한하며 선임 시 집중투표의방법은 적용하지 않는다. / ② / 사외이사는 주주총회에서 선임한다 / . 단, 후보자격은추천위원회에서 추천된 자에 한하며 선임 시 집중투표의방법은 적용하지 않는다. / ③ / 사내이사와 사외이사는 그 종류를 구분하여 주주총회에서별개의 안건으로 선임한다. / ④ / 사내이사와 사외이사의 선임은 / 출석한 주주의 의결권의과반수로 하되 발행주식 총수의 4분의 1이상의 수로 하여야 한다. / 제30조의 1 ( / 감사의 선임 / ) / ① / 감사는 주주총회에서 선임한다 / . 단, 후보자격은추천위원회에서 추천된 자에 한하며 선임 시 집중투표의방법은 적용하지 않는다. / ② / 감사의 선임은 그 종류를 구분하여 주주총회에서별개의 안건으로 선임한다. / ③ / 감사의 선임은 / 출석한 주주의 의결권의 과반수로하되 발행주식총수의 4분의 1이상의 수로 하여야 한다.단, 의결권 없는 주식을 제외한 발행주식총수의 100분의 3을초과하는 수의 주식을 가진 주주는 그 초과하는 주식에관하여 의결권을 행사하지 못한다 | 선임 대상별 / 내용의 / 명확화
