# 04 배당기준일 태깅 — 정관의 결산배당 기준일 조항

코스피 825사·코스닥 1,784사 정관(사업보고서 첨부본)에서 **결산배당을 받을 주주를 정하는 기준일** 조항을 찾아 회사마다 태그 하나를 달았다.
코스닥은 아래 [코스닥](#코스닥-2026-11-16-추가-사용자-지시) 절 — 같은 지침·발췌로, Claude API 대신 Claude Code 서브에이전트가 판별했다.
사용자 지시(2026-11-16): 정관에서 '배당을 받을 주주를 확정하기 위한 기준일'·'주주명부에 기재된 주주' 같은 내용을 찾아
아래 셋 중 하나를 단다. 정관 전체를 LLM 에 넣지 말고, 관대한 키워드로 해당 조항 앞뒤를 추린 뒤 LLM 으로 판별한다.

| 태그 | 뜻 | 대표 문구 |
|---|---|---|
| `정관no` | 이사회로 정하는 때 — 정관이 날짜를 고정하지 않는다 | "이사회결의로 제1항의 배당을 받을 주주를 확정하기 위한 기준일을 정할 수 있으며, … 2주 전에 이를 공고" |

## 웹페이지 탭 (s10 → site/dividend.js)

코스닥을 붙인 뒤(2026-11-16 밤) 세 탭 모두 **시장 열·시장 필터**가 있고, 배당기준일 취합 탭은 전체·코스피·코스닥 단추로 바꿔 본다(라디오 + CSS).
화면의 태그 이름은 **N · Y · YorN**(= 정관no · 정관yes · 정관yesorno, 사용자 지시 2026-11-17, 색은 그대로)이고 결과 파일 값은 바꾸지 않았다. 글 속에서는 '정관 N' 처럼 적는다.
'정관' 칸에는 태그만 둔다. 첨부 정관과 태그가 다른 180사는 근거 문구 칸 맨 위 라벨로 까닭을 보인다: 주총에서 바뀐 173사 = 굵은 크림슨 **주주총회 안건** '(사업보고서 첨부 정관이 이후 주주총회를 통해 변경됨)', 첨부 정관을 읽을 수 없어 다른 자료로 정한 7사 = 쓴 자료 이름 **전년도 정관**(SK이터닉스 · 레이 · 청담글로벌 · 이씨에스) · **사업보고서 본문**(민테크)은 짙은 보라, **주주총회 안건**(OCI · 삼양패키징)은 크림슨, 뒤에 작은 글씨로 못 읽은 이유(암호화된 PDF · DART 가 PDF 를 제공하지 않음 · 정관 이미지가 중간에 끊김).

**상장공시시스템 신고 대조 (2026-11-17, 사용자 지시).** 배당기준일 탭 '정관' 칸 옆에 회사가 상장공시시스템에 신고한 배당기준일 조건('신고', 엑셀 I열: Y = 특정일 · N = 이사회 결의로 정한 날 · 미입력)과 '신고 기준일'(J열)을 같은 색 아이콘으로 둔다(코스피만, s02e → s10). 일치 = 정관 N·신고 N, 정관 Y·신고 Y 이고 신고 기준일이 '결산' 날짜와 같음('말일'은 그 달 마지막 날). 정관 YorN 은 상장공시시스템에 YorN 이 없어 어느 쪽으로 신고했든 **불일치**. 결산기가 여럿인지 모르는 리츠(`settle_months` 없음)는 결산기말 고정이면 결산월과 3개월 간격 달의 말일을 일치로 보고 '참고'로 적는다(7사). 불일치는 빨간 바탕, 미입력은 회색 바탕이고 '신고 대조' 필터(불일치 + 미입력 묶음 포함)와 취합 탭 '상장공시시스템 신고 × 정관 (코스피)' 표로 본다.

## 한계

* **`tag` 는 사업보고서 첨부 정관 시점이다.** 12월 결산 회사의 첨부 정관은 대개 그해 3월 정기주총 **전** 판이다.
  `tag_current` 는 소집공고 안건 중 결산배당 기준일을 바꾸는 것을 KIND 가결로 확인해 반영했다 — 제출 뒤 공고(s09d)와, 2026-11-17 부터는 원본 제출
  **전** 90일 안에 접수된 공고(그해 정기주총, s09i)까지. 90일보다 앞선 임시주총 안건, KIND 결과공시 안건 표를 읽지 못한 공고(코스닥 2), 결과공시가
  없거나 정관 안건이 없던 공고(코스피 2 · 코스닥 2)는 반영하지 않았다(특이사항 '주총 안건 가결 확인 못 함'). 보해양조처럼 안건 반영본을 미리 첨부한 회사도 있다.
* 정관이 '정할 수 있다'고 해도 실제로 배당액을 먼저 정하고 기준일을 뒤로 잡았는지는 별개다 — 공시(「현금ㆍ현물배당을 위한 주주명부폐쇄(기준일) 결정」,
  「현금ㆍ현물배당 결정」의 배당기준일)나 사업보고서의 '배당관련 예측가능성' 기재로 따로 확인해야 한다.
* 스캔 정관(이미지 164·PDF 일부)은 Opus 전사문으로 판별했다. 인용할 때는 `charter_url` 원본과 대조한다.
* `interim`·`quarterly` 의 `없음` 은 "발췌에 그 조가 보이지 않음"이다. 발췌 앵커에 중간·분기배당이 있어 실제 없음과 거의 같지만 전문으로 확인하지는 않았다.
* LLM 판별은 같은 입력이라도 다시 돌리면 드물게 달라질 수 있다 — 결과(`s09b_results.jsonl`)를 저장해 두고 다시 보내지 않는다.
